## Quirks
- **Catalog shard inventory (HEAD):** 42 generated `packages/ai/src/providers/<id>.models.ts` shards, each header "auto-generated by scripts/generate-models.ts — Do not edit manually" (`packages/ai/src/providers/openai.models.ts:1-2`): amazon-bedrock, ant-ling, anthropic, azure, baseten, cerebras, cloudflare-ai-gateway, cloudflare-workers-ai, deepseek, fireworks, github-copilot, google, google-vertex, groq, huggingface, kimi-coding, meta, minimax, minimax-cn, mistral, moonshotai, moonshotai-cn, nvidia, openai, openai-codex, opencode, opencode-go, openrouter, qwen-token-plan, qwen-token-plan-cn, qwen-token-plan-individual, radius, together, typesafe, vercel-ai-gateway, xai, xiaomi, xiaomi-token-plan-{ams,cn,sgp}, zai, zai-coding-cn. Some shards also export image catalogs (`OPENAI_IMAGE_MODELS`, `openai.models.ts:8`). Regional/plan variants are separate thin provider files over `openai-completions` with own env key, e.g. `packages/ai/src/providers/qwen-token-plan-cn.ts:3-9` (`QWEN_TOKEN_PLAN_CN_API_KEY`); same pattern `xiaomi-token-plan-{ams,cn,sgp}.ts`. Typed JSON import shim: `packages/ai/src/providers/data-json.d.ts`.
- Runtime `detectCompat` and generator `detectOpenAICompletionsCompat` duplicate logic and drift (`openai-completions.ts:1642,1675` vs `generate-models.ts:749-750,781`); which wins for custom models at built-in URLs (unverified).
- Model catalog JSON gitignored → whether e.g. `gemini-2.5-flash-lite` exists on Vertex can't be checked from source (unverified).
- OpenAI caches never warmed because `promptCache` deliberately unset (`generate-models.ts:989-991`) — see [[cache-warming]].
- Default-model-per-provider table needs edits whenever upstream removes a model (`49b9df489`, `28fd59086`, `e1787702d`, `6f7551516`) — see [[pi--model-resolution|model-resolution]].
- `pi.dev` overlay + R2 publishing = catalog freshness without a pi release.
