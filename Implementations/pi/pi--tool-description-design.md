## Mechanism
- Three model-facing text channels per tool: API `description` + param descriptions (provider tool declaration); `promptSnippet` (one line in `<tools>` system-prompt section, opt-in since `7817e9b22`); `promptGuidelines` (bullets in `<rules>`, deduped, emitted only for **declared** tools — `packages/coding-agent/src/core/system-prompt.ts:88-125,150`, `c30840c2e`). Snippets/guidelines exported as `*ToolSystemPromptContribution` constants (`9ab91fb93`, reused by durable prompt). Prompt-side mechanics → [[dynamic-tool-guidelines]].
- **Limits interpolated from constants** so text never drifts from code: `DEFAULT_MAX_LINES = 2000`, `DEFAULT_MAX_BYTES = 50*1024` (`packages/coding-agent/src/core/tools/truncate.ts:11-12`) templated into read/bash/grep/find/ls descriptions since `de77cd141` (2025-12-07); `GREP_MAX_LINE_LENGTH = 500` (`truncate.ts:13`); per-tool `DEFAULT_LIMIT` 100/1000/500 (`grep.ts:41`, `find.ts:41`, `ls.ts:23`).
- **Recovery path stated in description and in result notices**: read "Use offset/limit for large files. When you need the full file, continue with offset until complete." (`read.ts:96`); notices "[Showing lines X-Y of N. Use offset=K to continue.]" (`read.ts:184-199`), first-line-too-big "Use bash: sed -n 'Np' path | head -c 51200" (`read.ts:179-183`); bash "[Showing lines a-b of T. Full output: <path>]" (`bash.ts:338-356`); grep "Use limit=200 for more, or refine pattern … Use read tool to see full lines" (`grep.ts:286-303`); find "Use limit=2000 for more, or refine pattern" (`find.ts:281-293`); edit "Found N occurrences … Please provide more context to make it unique" (`edit-diff.ts:264-273`), overlap "Merge them into one edit or target disjoint regions." (`:341-350`). All notices are model-visible text ("All notices now in text content (LLM sees them)", `b813a8b92`). See [[tool-output-truncation]].
- **One input shape**: edit collapsed to `edits[]` only (`e773527b3`, #2639); legacy shapes fixed in code via `prepareArguments` ([[tool-argument-repair]]), "without polluting the public schema" (`b5f425ad1`).
- **Long reference offloaded to docs**: codemode description keeps "one line per global"; full reference in `packages/coding-agent/docs/codemode.md` ("Read … first", `codemode/tool.ts:154`); errors "point the way back" (close-match suggestions, "Did you mean …" up to 5, `packages/codemode/src/runtime/prelude-source.ts:238`) instead of documenting upfront (`6f1072cc0`: default GPT-5.6 request ~5,300 → ~3,300 tokens).
- **Byte-stable descriptions**: codemode/tool_search descriptions never list deferred tools, tool counts or MCP instructions "so it no longer changes when MCP servers connect" (#10212, CHANGELOG `:198`; `tool-search/tool.ts:216-219`; `codemode/tool.ts:241-247`); volatile server data moved into patchable `mcp_servers` system-prompt section → [[cache-stable-prompt-prefix]], [[transcript-carried-system-prompt]].
- **Orchestrator can rewrite other tools' descriptions**: `prepareLoadout(loadout) → {descriptions, hiddenDeclarations}` (`packages/coding-agent/src/core/extensions/types.ts:546-568,624`); codemode `on` mode appends "Codemode: `tools.x(args)` resolves to …" to declared tools; `only` mode hides direct declarations (`codemode/tool.ts:330-378`). Guidelines travel inside the codemode description because system-prompt rules cover only declared tools (`:160-175`).
- **Durable variant of notices**: truncation/continuation remarks are `diagnostics`, not content, rendered as `<harness>\n[severity] message\n</harness>` (`packages/durable/src/harness/tool.ts:454-485`) → [[harness-diagnostics-channel]].

## Quirks
- Edit not-found error still says "must match exactly including all whitespace and newlines" although a fuzzy fallback exists (`edit-diff.ts:253-262`) — conservative instruction, lenient execution ([[fuzzy-edit-matching]]).
- Descriptions are short (~40-90 tok each, findings 04 estimate) and contain no examples; examples only in param descriptions of find/grep globs (`find.ts:26-32`, `grep.ts:21-33`).
- Tool texts are model-agnostic: no per-model description variants (unverified exhaustively; only Anthropic OAuth tool *renaming* exists → [[provider-identity-shim]]).
- Prompt-level counterpart lesson (04 findings): imperative always-on rules become actions every turn → [[guideline-softening]].
