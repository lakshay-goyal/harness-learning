## 3 most surprising findings

1. **The log is the program state, including the system prompt.** Before every provider request pi rebuilds model context from the JSONL session tree, not memory (`packages/coding-agent/src/core/agent-session.ts:793-799`, `466db0fec`). System-prompt sections and tool declarations live *in the transcript* as delta messages, so a tool change appends instead of rewriting the cached prefix (`9e05370b2`). Failed retries and overflow attempts stay on disk but are hidden by append-only `context_edit` entries. Pushed further, this became `packages/durable`: a crash-resumable second harness written spec-first by agents in ~6 weeks, which replaced the earlier in-agent harness (`7fd478a2e`).
   → [[context-projection]] · [[transcript-carried-system-prompt]] · [[context-edit-overlay]] · [[durable-execution]] · [[spec-driven-agentic-development]]

2. **"Minimal" is a moving manifesto, and several of its "nevers" have been reversed.**
   - MCP was rejected because "A 225-token README beats a 13,000-token MCP server description" (`60e4fcf01`). It then shipped as a built-in extension (`8562bcf66`), with tools hidden by default behind codemode and BM25 tool search so the prompt cost stays low.
   - Sub-agents ("You're the orchestrator", `e9935beb5`) came back as first-class task-owned conversations in durable.
   - AGENTS.md was trust-gated for only 4 days (`89a92207f` → `5cb4f597f`). Pi now declares prompt injection out of scope.
   - The README Philosophy section itself was deleted (`25cc5c7bf`).
   → [[Absences]] · [[no-builtin-mcp-reversed]] · [[no-subagents-core]] · [[deferred-tool-loading]] · [[project-trust-gate]]

3. **Most pain lives at the provider boundary, not in the loop.**
   - Reasoning/thinking replay is the #1 fix theme: 151 commits and 267 changelog bullets.
   - Claude started emitting literal `</thinking>` because foreign reasoning was replayed wrapped in tags (`16e142ef7`).
   - Gemini unsigned tool calls took 4 strategies (`b18f401d9` → `5d3e7d5aa` → `a0d839ce8` → `f7df47408`).
   - Retryability and context overflow are decided by ever-growing regex lists over error text. Rate limits got misread as overflow and triggered compaction (`25707f9ad`, `a3bf1eb39`, `661619e87`).
   - Tool calls from length-truncated responses used to *execute*, because the lenient JSON repair made cut-off arguments look valid. Now they are refused (`351efc828`).
   → [[thinking-tag-mimicry]] · [[gemini-unsigned-tool-call-replay]] · [[retry-classifier-regex-sprawl]] · [[rate-limit-misread-as-overflow]] · [[truncated-tool-call-guard]] · [[cross-provider-handoff]]

## 1 thing to build
**Projected context with an edit overlay.** Keep an append-only event log. Derive the request each turn as `latest compaction summary + kept entries + latest context_edit per target`. Store the system prompt and tool set as diff messages in the log. You get crash-safe resume, honest audit history, failed attempts that never re-enter context, and cache-stable prefixes when tools change. Start from [[pi--context-projection|pi]] and [[pi--transcript-carried-system-prompt|pi]].

## 1 question to argue
Pi gives the agent full user permissions: no approval prompts ("Security theater", `3424550d2`), no cwd confinement (once added in 0.11.7, later dropped, see [[read-path-traversal]]), and no sandbox. It loads AGENTS.md from untrusted repos and calls prompt injection unpreventable. **Is "honest YOLO + opt-in isolation" ([[tool-only-isolation]], [[tool-call-gate]]) safer in practice than permission prompts that users click through?** Counter-evidence: the shipped sandbox example reads repo `.pi/sandbox.json` without a trust check, so a repo can switch off a global sandbox ([[repo-config-disables-sandbox-plugin]]).
